# Teste Prático – Funcionários da Indústria

Aplicação Java de console que cadastra os funcionários de uma indústria e executa as operações pedidas no teste.

## Tecnologias

- Java 17
- Maven
- JUnit 5

## Como executar

```bash
mvn compile exec:java   # roda a aplicação
mvn test                 # roda os testes
mvn package && java -jar target/teste-pratico-java-2-1.0.0.jar
```
